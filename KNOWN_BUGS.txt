* Passing structs by value uses dynamically compiled foreign-funcall
  wrappers with concrete struct types to bypass CFFI's variadic
  function limitation (cffi#290). Targets arm64 only — x86-64
  support has been removed.

* Use of unexported CFFI symbols for type introspection and
  marshaling (e.g. cffi::*default-type-parsers*, cffi::translate-objects,
  cffi::canonicalize-foreign-type, cffi::parse-name-and-options,
  cffi::foreign-typedef, cffi::type-keyword, cffi::actual-type).
  These are used to resolve typedefs, look up type definitions, and
  marshal arguments — not for the original variadic workaround,
  which has been replaced by dynamically compiled foreign-funcall
  wrappers on arm64.

* Struct field access inside define-objc-method must go through
  helper defuns (e.g. rect-size, point-x) rather than slet*
  macrolet accessors, because defcallback evaluates its body in a
  null lexical environment.
